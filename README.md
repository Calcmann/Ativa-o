# Publicação rápida

Este pacote contém o arquivo `analise-ativacao.html`.

## Opção 1 — Netlify Drop (sem conta)
1. Acesse https://app.netlify.com/drop
2. Arraste e solte o arquivo `analise-ativacao.html`.
3. Copie a URL gerada.

## Opção 2 — GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `analise-ativacao.html`.
3. Em *Settings → Pages*, selecione `main` e a pasta `/ (root)`.
4. Acesse `https://<seu-usuario>.github.io/<repo>/analise-ativacao.html`.

## Observação
OneDrive/SharePoint não executam HTML como site público; o arquivo é baixado em vez de renderizado como página.
